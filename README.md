# Enrollment_form
A basic web application that allows users to add, update, and reset student records in a database. It uses HTML, Bootstrap 3, jQuery, and connects to a backend using JPDB (JSONPowerDB).

## 🚀 Features

- Add new student records with:
  - Roll-No
  - Full Name
  - Class
  - Date of Birth
  - Address
  - Enrollment Date
- Update existing student records based on Roll-No
- Reset the form to clear all fields
- Form validation to ensure required fields are filled
- Backend integration with JSONPowerDB

## 🛠️ Technologies Used

- HTML5
- CSS3 (via Bootstrap 3.4.1)
- JavaScript (jQuery)
- [JSONPowerDB (JPDB)](http://login2explore.com/) for backend storage


## 📌 JPDB Setup
Uses pre-configured DB:  
    
-DB Name: SCHOOL-DB

-Relation/Table Name: STUDENT-TABLE

-Connection Token: Defined in index.js


## 📋 How to Run

git clone https://github.com/your-username/student-enrollment-form.git
